# 우선순위와 완료 기준

## 기준

현재 구현은 정적 탐색 프로토타입이며 수집 데이터의 형식과 역사적 사실은 별개다.
이 문서는 구현 완료 목록이 아니라 다음 작업의 순서와 검증 기준이다.
현재 수치와 근거의 한계는 [DATA.md](DATA.md), 실행 구조는 [ARCHITECTURE.md](ARCHITECTURE.md)를 따른다.
기능 확대보다 연대·지리·권리 메타데이터의 신뢰 경계를 먼저 바로잡는다.
각 작업은 작성·구현 후 별도 검토자의 확인을 받고 완료로 표시한다.
아래 완료 기준은 아직 충족했다고 주장하지 않으며 일정도 확약하지 않는다.

## 1. 실제 연대·지리 근거와 메타데이터

우선 대상은 한국 세기 미상 710건과 왕조 범위를 12세기로 잘라 넣은 중국 56건이다.
한국의 12세기 표제 23건도 페이지 전체 문자열 대신 개별 편년 근거를 확인한다.
원문 연대, 정규화 범위, 근거 종류, 확인일, 검토 상태를 분리해 보관한다.
연대 미상 자료는 미상으로 남기고 기본 세기 비교군과 구분한다.
비교용 가정은 사용자가 명시적으로 포함할 때만 보이게 하는 방식을 검토한다.

위치는 제작지·출토지·소장처·시대 대표점을 구별하고 개별 출처를 연결한다.
강진·카이펑·항저우·상하이 대체점과 나선형 표시점을 실제 유적 좌표로 승격하지 않는다.
증거 없는 좌표는 `unknown`·`null`로 남길 수 있도록 표시 정책을 함께 바꾼다.
소장처 확인과 독립적인 소장 이력 검증을 분리한다.
이미지별 권리 표기, 원문 권리 페이지, 확인일과 미확인 상태도 기록한다.
이는 향후 메타데이터 설계이며 현재 스키마에 이미 있는 필드라고 가정하지 않는다.

완료 기준:

- 샘플의 원문 근거를 독립 검토자가 따라가며 편년·위치 해석을 재현한다.
- 원문에 없는 연대·위치가 확정값으로 표시되지 않는다.
- 세기 미상·왕조 기반 추정·개별 편년을 UI와 데이터에서 구분한다.
- 이미지 URL 존재와 재사용 허가를 구분하고 미검토 상태를 숨기지 않는다.

## 2. 안전한 수집과 재현 가능한 갱신

현재 수집기는 출력 경로가 고정되어 있고 수동 보정을 포함한 스냅샷을 덮어쓴다.
실패한 개별 상세를 건너뛰며 결과가 일부 줄어도 양국이 비어 있지 않으면 저장한다.
일반 점검이나 CI에서 원격 수집을 실행하지 않는 경계를 유지한다.

먼저 네트워크 조회 없이 옵션을 확인하는 도움말과 별도 출력 경로를 설계한다.
검토용 수집 결과를 만들되 기존 스냅샷은 바꾸지 않는 dry-run 동작을 명확히 정의한다.
기존 파일 교체는 검토·승인한 경우에만 수행하고 교체 전후 차이를 남긴다.
요청 시간 제한, 실패 내역, 캐시·재개, 안정된 ID 정렬을 순서대로 보강한다.
원문 스냅샷 또는 작은 HTML fixture로 정규식·파서 회귀를 검증한다.
`outveiw-tit` 처리와 과거 제목 수동 보정 10건의 재발 방지를 검토한다.
검색 범위와 수집 시점은 기록하되 전체 소장품 수집이라고 표현하지 않는다.

완료 기준:

- dry-run·실패 실행이 기존 `data/artifacts.js`를 바꾸지 않는 테스트가 있다.
- 결과·누락·재시도·중단 상태를 검토자가 확인할 수 있다.
- 같은 fixture는 같은 결과와 순서를 만들고 제목 처리 회귀를 검출한다.
- 출력 검증과 승인 없이 부분 수집 결과가 운영 스냅샷을 대체하지 않는다.

## 3. 클러스터 탐색·이미지 실패·안전한 출력

나선 분산 대신 대표점의 묶음 수와 개별 유물을 오갈 수 있는 탐색을 우선 검토한다.
표시용 분산과 실제 좌표를 명확히 구별하고 소장처·추정 위치 혼동을 줄인다.
상세·팝오버의 닫기, 선택 유지, 키보드 포커스와 좁은 화면 조작도 함께 점검한다.
원격 이미지 실패·지연 시 안정된 크기의 대체 화면과 출처 접근을 제공한다.
WebGL 미지원 시에도 목록과 데이터의 한계를 읽을 수 있는 경로를 검토한다.

목록·상세·팝오버뿐 아니라 Globe.gl 툴팁을 포함한 모든 HTML 삽입 지점을 조사한다.
텍스트는 안전한 DOM API를 사용하고 이미지·출처 URL의 프로토콜도 검사한다.
일부 필드만 이스케이프하거나 수집기의 태그 제거만 신뢰하는 것으로 완료하지 않는다.

완료 기준:

- 같은 위치의 여러 유물을 포인터·키보드·모바일로 구별해 선택할 수 있다.
- 깨진 이미지와 WebGL 실패에서 정보 접근 및 화면 배치가 유지된다.
- 제목·설명·한자·URL에 넣은 악의적 fixture가 HTML·스크립트로 실행되지 않는다.
- 상세·목록·팝오버·점 툴팁 전체에 같은 신뢰 경계가 적용된다.

## 4. 큰 목록 성능과 브라우저 회귀 검증

현재 검색 입력마다 목록 전체와 상세를 다시 만들고 점 데이터도 갱신한다.
먼저 현 스냅샷 892건과 더 큰 합성 데이터에서 검색·선택 비용을 측정한다.
측정 결과에 따라 검색 지연 제어, 부분 갱신, 페이지 처리·가상화를 선택한다.
성능 개선이 선택 상태, 보조기기 탐색, 필터 결과의 정확성을 깨지 않게 한다.

오프라인 데이터 검사와 별도로 실제 HTTP·WebGL 브라우저 테스트를 마련한다.
첫 렌더, 검색·문화권·분류, 빈 결과, 세기 이동, 선택 해제, 회전·줌을 검증한다.
데스크톱·모바일 화면 크기, 이미지 실패, HTML 주입 회귀도 포함한다.
외부 이미지 응답에 좌우되지 않는 fixture 테스트와 원격 수동 확인을 구분한다.

완료 기준:

- 환경·데이터 크기·측정값과 성능 예산을 기록하고 변경 전후를 비교한다.
- 현재 스냅샷의 초기 12세기 결과와 필터·선택 결과를 자동 검사한다.
- WebGL 캔버스가 비어 있지 않은지와 주요 화면 겹침을 스크린샷으로 확인한다.
- CI의 오프라인 통과와 브라우저·원격 출처 확인의 실행일·결과를 따로 남긴다.

## 5. 장기: Top 10 박물관 확장

상위 10개 박물관이라는 범위는 장기 후보이며 현재 지원 규모나 객관적 순위가 아니다.
대상 선정 기준은 소장 분야, 공개 메타데이터, 권리 조건, 지속 가능한 접근성으로 먼저 합의한다.
기관별 공식 API·목록 구조를 조사하고 이용 조건에 맞는 접근 방식을 선택한다.
수집량 목표보다 근거 있는 연대·위치와 검토 가능한 이미지 권리의 비율을 먼저 본다.
박물관·문화권·언어를 확장할 때 기존 ID와 미상값 정책을 유지하거나 명시적으로 이관한다.

착수 조건은 1~4단계의 신뢰성·갱신 안전성·탐색·검증 경계를 먼저 확보하는 것이다.
새 기관은 작은 검토 표본부터 추가하고 독립 검토 후 범위를 넓힌다.
문서의 로컬 구조 검증은 새로운 브라우저 확인이나 원격 박물관 메타데이터 검증을 대신하지 않는다.
